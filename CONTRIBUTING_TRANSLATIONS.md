# Contributing Translations

To contribute to the Romanian translation of *The Rust Programming Language*, follow these steps:

1. **Setup**: Ensure you have the DeepL API key configured in .ai/mcp/mcp.json.
2. **Translation**: Run the batch translation script: python tools/batch_translate.py.
3. **Review**: Perform a manual review of the generated .ro.md files, documenting issues in REVIEW_NOTES.md.
4. **Refinement**: Fix encoding issues and improve the linguistic quality of the translations.
